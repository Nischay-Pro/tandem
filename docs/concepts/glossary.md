# Tandem glossary

Use these terms consistently across the guides.

| Term                | Meaning                                                                                                                                    |
| ------------------- | ------------------------------------------------------------------------------------------------------------------------------------------ |
| **Actual**          | Actual Budget, the budgeting application and server that holds the authoritative budget.                                                   |
| **Actual account**  | The account used to sign in to an Actual server and access its budgets.                                                                    |
| **Budget**          | One Actual household or personal budget, including its accounts, categories, and transactions.                                             |
| **Budget password** | The extra password Actual uses to unlock an end-to-end encrypted budget. Tandem asks for it when needed and does not save it.              |
| **Tandem API**      | The server component that connects the phone app to Actual and confirms supported changes.                                                 |
| **Local copy**      | The budget data stored on a phone after it has synced. It remains readable offline and is not a substitute for a backup.                   |
| **Pending change**  | A change saved on the phone that Actual has not yet confirmed. The app lists these in **Pending Changes**.                                 |
| **Conflict**        | A case where Actual changed or removed the same item while the phone had an edit waiting. Tandem keeps the edit for review.                |
| **Synced**          | A change Actual confirmed and Tandem read back successfully. See [sync status names](../using/sync-status.md) for the other status labels. |

For the data Tandem can read, see [Architecture and trust](architecture-and-trust.md).
